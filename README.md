# Herman Apps — Umbrel community app store

Add this store on your Umbrel: **App Store → ⋯ → Community App Stores**, then paste
this repository's URL.

| App                       | Description                                                |
| ------------------------- | ---------------------------------------------------------- |
| [Spotter](herman-spotter) | Self-hosted strength-training log and AI coach             |
| [Gleaner](herman-gleaner) | Handwritten reMarkable notes become an open-loop task list |

Each app folder is synced here by its own repo's release workflow, which pins each
release's image digest: `herman-spotter/` from the
[`spotter`](https://github.com/mherman1990/spotter) repo and `herman-gleaner/` from the
[`Gleaner`](https://github.com/mherman1990/Gleaner) repo, both under `umbrel-store/`.
This README and `umbrel-app-store.yml` live in the `spotter` repo's `umbrel-store/`.
Edit each file at its source, not in the store repo.
